# User Persona Studio v4.0

Расширение SillyTavern для управления стороной `{{user}}`: внутреннее состояние, отношения, мир/вещи, визуальные референсы, режиссёрские подсказки и личные заметки.

## Главное
- Всё работает поверх обычного ролевого запроса. Отдельный API для режиссуры не требуется.
- Разовые OOC-команды, режиссёрские подсказки и визуалы очищаются после ответа модели.
- Визуальные референсы добавляются в следующий пользовательский запрос как inline media. Нужна Chat Completion модель с vision и включённая отправка inline images в SillyTavern.
- Карточки мира имеют режимы: не отправлять / один раз / всегда.
- Личные заметки никогда не отправляются модели.
- Есть предпросмотр точного текстового блока и JSON backup.

## Обновление с v3.3
Заменить `index.js`, `style.css`, `manifest.json`. Старое состояние текущего чата автоматически переносится при первом открытии.
